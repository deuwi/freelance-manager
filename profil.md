# Profil freelance — données utilisateur

Copié dans `~/.freelance-manager/profil.md` au premier lancement, puis rempli
avec l'utilisateur — jamais inventé. Utilisé par `references/strategies.md`
pour adapter les conseils. Ne pas y mettre de données bancaires ni
d'identifiants.

- **Stack / spécialités** : (langages, frameworks, domaines)
- **Localisation & remote** : (région ; remote ok ou non)
- **Statut** : micro-entrepreneur BNC — les calculs de `fm.py` supposent ce
  régime ; adapter `config.json` si les taux diffèrent
- **Réseau direct** : anciens employeurs, ex-collègues, clients passés, ESN
  locales à contacter en premier
- **Plateformes actives** : celles où le profil est à jour et la réponse
  < 24 h
- **Marque contenu / audience** : nom, canaux, lead magnet — ou « aucune »
- **Projets annexes** : temps régulier hors régie (contenu, produits, side
  projects) — ou « aucun »
